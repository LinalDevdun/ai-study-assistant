 🎓 AI Study Assistant

A full-stack web application that allows students to create study subjects and chat with an AI Tutor to explain complex academic concepts.

🚀 Tech Stack
   Frontend: React.js, Vite, React Router, React Markdown
   Backend: Node.js, Express.js
   Database: PostgreSQL
   Authentication: JSON Web Tokens (JWT)
   AI Integration: Google Gemini API

 🛠️ How to Run Locally

 1. Database Setup
  Install PostgreSQL and create a database named `study_assistant`.
 Create `users` and `subjects` tables.

 2. Backend Setup
   Navigate to the `/backend` folder.
   Run `npm install`
  Create a `.env` file with your DB credentials, JWT secret, and Google Gemini API key.
  Run `node index.js`

 3. Frontend Setup
  Navigate to the `/frontend` folder.
  Run `npm install`
  Run `npm run dev`
